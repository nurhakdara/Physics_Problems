# 4. Magnetic Torque

## Given

Length of rectangular loop:

l = 10 cm = 0.10 m

Width of rectangular loop:

w = 5 cm = 0.05 m

Current in loop:

I = 2 A

Magnetic field:

B = 0.3 T

--------------------------------------------------

# Main Formula

Magnetic torque on a current loop:

τ = N I A B sinθ

Where:

τ = magnetic torque  
N = number of turns in the loop  
I = electric current  
A = area of loop  
B = magnetic field  
θ = angle between magnetic field and normal to the loop  

Since no number of turns is given:

N = 1

--------------------------------------------------

# Step 1 — Calculate Area of Loop

A = l × w

= 0.10 × 0.05

= 0.005 m²

--------------------------------------------------

# Step 2 — Determine Angle

The magnetic field is parallel to the plane of the loop.

Therefore, the angle between magnetic field and the normal vector is:

θ = 90°

So:

sin(90°) = 1

--------------------------------------------------

# Step 3 — Calculate Torque

τ = (1)(2)(0.005)(0.3)(1)

τ = 0.003 N·m

--------------------------------------------------

# Final Answer

Magnetic torque on the loop:

τ = 3 × 10^-3 N·m
