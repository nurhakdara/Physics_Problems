# 3. Biot–Savart Law

## Given

Length of wire segment:

L = 0.1 m

Current:

I = 3 A

Distance from wire to point P:

r = 0.2 m

Permeability of free space:

μ₀ = 4π × 10^-7 T·m/A

Angle between wire segment and line to point P:

θ = 90°

Since the segment is perpendicular:

sin(90°) = 1

--------------------------------------------------

# Main Formula

Biot–Savart Law:

dB = (μ₀ / 4π) × (I L sinθ / r²)

Where:

dB = small magnetic field produced by current element  
μ₀ = permeability of free space  
I = electric current  
L = length of current segment  
θ = angle between current direction and position vector  
r = distance from current segment to point P  

--------------------------------------------------

# Step 1 — Substitute Values

dB = (4π × 10^-7 / 4π) × (3 × 0.1 × 1 / (0.2)²)

--------------------------------------------------

# Step 2 — Simplify

First cancel 4π:

dB = 10^-7 × (0.3 / 0.04)

dB = 10^-7 × 7.5

dB = 7.5 × 10^-7 T

--------------------------------------------------

# Direction of Magnetic Field

Using the right-hand rule:

- Point the thumb in the direction of current.
- Curl fingers toward point P.
- The magnetic field direction is perpendicular to both.

--------------------------------------------------

# Final Answer

Magnetic field at point P:

dB = 7.5 × 10^-7 T
